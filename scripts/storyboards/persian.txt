# Persian into the note editor, and the mixed-direction case beside it.
#
# `xdotool type` remaps keysyms to reach characters the layout does not carry, so what this exercises
# is the **keymap** path — the same events an `ir(pes)` layout produces, delivered as ordinary key
# presses. It does **not** exercise a composing input method (`zwp_text_input_v3`); Persian does not
# need one, but see `docs/environment/desktop-capture.md` for what that leaves unproven.
#
# **The nav x is `%LX+86%`, not a literal 86.** It was a literal until #132, and it had been missing
# its target since #131 put a 28px page margin in front of it — the click landed on *Review*, so this
# storyboard photographed the Review screen three times under three editor names and said nothing.
# `baseline.txt` was migrated to `%LX%` when the frame landed and this file was not; that is the whole
# failure. A storyboard cannot tell you it missed (#122), so both files are now on the same token.
mousemove %CX% 600 click 1
sleep 1
mousemove %LX+86% 11 click 1
sleep 1.2
mousemove %CX% 87 click 1
sleep 1.5
mousemove %CX% 300 click 1
sleep 0.8
sh xdotool type --delay 120 'سگ در خانه است.'
sleep 1.5
shot 08-editor-persian-front
mousemove %CX% 335 click 1
sleep 0.8
sh xdotool type --delay 120 'the dog is in the house'
sleep 1.5
shot 09-editor-persian-and-latin
