# The Notes destination in **Persian** — the editor's fields and card face, and a note-list row.
#
# **1280×800 only, and deliberately so.** This is the one storyboard in the set that has to aim at a
# control *inside* the editor, and the editor takes its own wider frame (#131, `frame::cap_for` →
# 1120). So its column's left edge is 80 at 1280 where the list's is 320, and the harness has a
# token for the **list's** frame (`%LX+n%`) and none for the editor's.
#
# `%CX%` — 640 — reaches an editor field at 560 and lands **fourteen pixels past its right edge** at
# 1280. `persian.txt` aims that way and has been missing there since #131; the first run of this
# file did the same, typed nothing, and photographed the French note under the Persian name. That is
# #122's silent miss arriving from a fifth side, and the first caused by a *frame* rather than by a
# coordinate. It is pinned here rather than papered over, the way `fixture-bench.txt` is, and #163
# owns the choice between adding the token and keeping the pin.
#
# **Both shots are self-evidencing**, which is what makes the pin tolerable: a run that missed leaves
# `06-editor-persian` showing `l'aube` / `dawn`, and leaves `07-list-persian` with no Persian row.
fixture backlog
mousemove %CX% 600 click 1
sleep 1
mousemove %LX+86% 11 click 1
sleep 1.2
mousemove %LX+24% 252 click 1
sleep 1.5
# The editor's Front field spans x 80..626 at 1280, so `%LX+30%` (=350) is inside it and `%CX%` is
# not. `xdotool type` remaps keysyms to reach characters the layout does not carry, so what this
# exercises is the **keymap** path — the same events an `ir(pes)` layout produces — and not a
# composing input method, which #129 ruled out of scope.
mousemove %LX+30% 265 click 1
sleep 0.5
key ctrl+a
sh xdotool type --delay 80 'سپیده‌دم'
sleep 0.8
mousemove %LX+30% 300 click 1
sleep 0.5
key ctrl+a
sh xdotool type --delay 80 'آغاز روز، پیش از برآمدن خورشید'
sleep 1
# Blur into empty page so the field autosaves (ADR-0021 §7) and the card pane redraws. The card face
# is the only place a storyboard reaches Persian at the display tier, and client-stack rule 7 makes
# that worth a capture rather than an assumption: within a family the first matching face wins, more
# than one shipped face carries the Arabic script, and nothing but looking tells them apart.
mousemove %CX% 500 click 1
sleep 1.5
shot 06-editor-persian
# Back to the list by *Done* — compact at x 80..200 at this width. Clicking the nav row's *Notes*
# does not work here: it is the current destination, so the click is a no-op and the next shot is
# the editor again under the list's name.
mousemove 140 49 click 1
sleep 1.5
# The row this produces is drawn **outside its own button and outside the page margin** — the button
# is allocated 61px at x=318..378 and the glyphs draw from x=274. See #162.
shot 07-list-persian
