# The file surface as #167 draws it: the file list on Settings, a preview of each of the four files
# behind it, then an import accepted, where it lands, and the same file opened again as a no-op.
#
# `fixture decks` and `files imports` are **both** needed, and both are named here rather than on the
# command line (#153, #166). Without the fixture the file set refuses to install, because its update
# file plans as *new deck* against any other collection; without the file set the list reads *"This
# app hasn't written any files yet."* under the name of a populated one.
#
# **Run it at 1280×800 and nowhere else.** The list is a block in the middle of Settings, below sync
# prose that wraps at one width and not the other, so the row y's are measured at this size after ten
# notches of scroll: `Chapters 1-4.cdeck` 265, `French A1.cdeck` 312, `collection.ccoll` 359,
# `فارسی and 2 more.cdeck` 406. Every shot is self-evidencing — a preview's heading is the name of the
# file it previews, so a row click that landed on the wrong row says so.
#
# **The preview opens at its top** however far down Settings the row was (`Band::scroll_to_top`), so
# nothing scrolls after a row is opened. The gate's primary sits on the reach line: its bottom edge is
# 165px above the page, so *Import* is at y 617 at this height, and *Cancel* is the text at its end.
#
# **Each preview restarts the app** — `restart` keeps the collection and the files and drops the
# scroll position — and the import comes **last**, because it is the one step that changes the
# collection every later shot would be taken against.
